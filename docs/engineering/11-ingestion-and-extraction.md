# Slice 03f — Text import and extraction boundary
15 November 2026. Prior exact head bfb9c0c812c6ee1f31c0e924d173e761f453c174, push run 43648320058: all four checks succeeded. Adds Rust code on the existing product branch. No new Cargo dependency, no external provider, no network request.

An actual UTF-8 import consumes bytes supplied to a trusted caller, not a locator fetch. An exact source/version/scope grant is required independently of the server-supplied import permit and expiration. The text is preserved without normalization and becomes an existing Source. No filesystem or HTTP capability; binding bytes, locator and version to authentic provenance remains a trusted importer responsibility. Same-version immutability must be enforced by a durable registry (not provided here). No true source acquisition from the internet, document parsing, or cryptographic evidence.

A bounded Extraction prepares excerpts from currently permitted local sources and binds the attempt to a trusted job ID, work revision and deadline. The JSON input is data only, with excerpt indices, text, question and max proposals; it omits source locators and IDs, but text itself can disclose data. No transmission to an external model is implemented or permitted by these checks. Real egress needs distinct approval, source policy, provider retention limits, cancellation, cumulative budget enforcement and network controls outside the model.

The parser requires exact version and job ID, known indices, limited nonempty propositions and directional polarity. Unknown fields, invented excerpt indices, duplicate items, stale revision, expiry and missing source grants are rejected. Excerpts are recovered from the original input, never generated by the model. Empty result is valid abstention. No model can supply reviewer status or emit a canonical event through this interface. Matching a citation does not prove entailment, source truth, or semantic appropriateness. Review remains an independent step; synthetic test demonstrates the real code path from imported text to retrieval to a proposed interpretation to a manually constructed reviewed assertion. No real reviewer, source, provider, or external action. Authority freshness and genuine attempt state are caller responsibilities; this library has no job runner or provider adapter, and no production safety claim. Work-private scope and publication of source IDs must still be governed by the product-level access boundary.

Five new tests cover exact bytes, limits, invalid UTF-8, grant revocation, expiry, changed revision, unknown fields, fabricated indices, mismatched job identity and abstention.
