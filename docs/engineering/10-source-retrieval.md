# Slice 03e — Scoped retrieval and identity hypotheses
15 November 2026. Previous exact head 06bc5cda237857eadf7cefcae084d3b9aa21c80c passed push 43647958723 and PR 43647962594. This adds a deterministic, local Rust baseline in the existing composition crate. No network request, external provider, model, new dependency, production data or deployment.

A bounded corpus accepts only exact pre-authorized source versions in one scope. Search rechecks supplied current grants before ranking, excludes unauthorized chunks from the hit count and limit flag, ranks by distinct normalized query term overlap and stable source/offset tie-breaks, and returns original UTF-8 byte spans for review. No generated citation, score interpreting probability, or automatic admission to Knowledge. Normalization is deliberately limited (case, selected Arabic marks/alef variants, punctuation); not full Unicode case folding, stemming, translation, multilingual synonym or semantic retrieval. 256 sources, 128KiB/source, 8MiB total, 2048-byte chunks, query 1024 bytes/32 terms, top 32. Chunks can split long words; retrieval quality and runtime benchmark not yet measured.

Identity hypotheses are upstream-reviewed associations with exact source spans and optional exact registry namespace/value. No authentication, registry lookup, proof of entailment, or automatic merge, even for a unique match. Conflicting exact identifiers remain distinct entity IDs. Matching uses normalized name token sequence or exact identifier. Source visibility is checked anew. Caller must enforce entity and reviewer grants beyond source visibility, and discard/rebuild corpus on revocation; stale caller-provided grants are NOT safe. Scope and source versions are not permissions themselves. No API, persistent entity registry, cross-scope aliases, ambiguity UX or true source acquisition. This is the retrieval/read side, not a live connection to the outside world. The corpus receives source content from a trusted importer; future adapters require explicit authorization, source/version integrity, retention, budgets and egress protections. 

Five synthetic tests cover bilingual exact excerpts, deterministic limiting, source removal noninterference in results (not timing), Unicode slicing, conflicting identity hypotheses, malformed evidence and scope denial. No real-world accuracy or performance claim. Existing archive, identity, retention, production security and design gates remain open. Next: authorized acquisition adapter and provider-neutral extraction proposal contract (untrusted output; human admission), then actual end-to-end source ingestion and benchmark.
