# Slice 03c — Grounded knowledge admission
15 November 2026. Prior head 2f381d2a381ded706c8116a802b7d61ae3a4dfe4 passed push 43646902465 and PR 43646906735. This slice connects reviewed source excerpts to the existing composition evaluator, in the same Rust crate, without new dependencies or providers.

Source = versioned identifier, scoped locator, acquisition time, exact UTF-8 text. Claim = immutable contextual proposition. Assertion = existing Evidence + exact byte span and excerpt + reviewer ID and review time. The caller supplies a pre-authorized single-scope snapshot and authenticated reviewer grants. This is an internal admission port, not a real review workflow or authentication service. Exact substring equality proves only that the supplied excerpt occurs within the supplied source version; it does NOT establish source authenticity, entailment, independence, or truth. No external URL fetch, generated citation, identity resolution or prompt processing. The review decision is upstream; no model may grant itself reviewer status.

Reject missing sources/claims, foreign scope, missing review grant, invalid source/version/timestamps, malformed byte ranges, fabricated excerpts and same-ID conflicting objects. Snapshot source and assertion revisions are immutable here; changes or revocation require a new authorized snapshot, discard of the old engine and re-evaluation of retained work. Earlier revisions are not durable and cannot be reconstructed from this library alone. Build a fresh evidence engine from admitted assertions. Existing direct Evidence upsert remains an internal low-level evaluator interface; not yet wired to the access/storage boundary and not a safe public API. Six synthetic tests cover Arabic exact spans, wrong text and offsets, invalid review/version/scope, contradiction and rebuild from a scope with no admitted assertions, and absent references. This does not test real grant revocation or deletion. Bounds: 256 sources, 128 KiB each, 8 MiB total source text, 2k claims, 4k assertions and 4KiB excerpt each. Memory/CPU benchmark needed, full traces may amplify costs. No installation of additional dependencies, no change to Cargo.lock or CI. New head must pass fresh checks.

Next: durable authorized source/claim/review/candidate event contracts; authenticated review and source admission, source retrieval/identity resolution with outbound controls; model adapter behind explicit budgets and evaluation; expression contract and first-state design in parallel once reviewed. Existing retention, backup, real identity, transport and security gates remain open. No live records, provider use, merge or deployment.
