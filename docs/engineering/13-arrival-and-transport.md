# 13 — Arrival, authority and the wire to the world
2026-11-15 · First connected-world engineering slice. The artistic world remains the same product.
The user asked to build the actual identity, memory, human relationships, intelligence and reality checks rather than continue only artistic refinements. Existing Rust kernel, PostgreSQL transactions, scoped replies, research admission and expression are retained. The first dependency is real discoverability of material authorized for a person, not a public directory or fabricated timeline.

Implemented: Kernel::arrival resolves verified actors against the registry and returns only owned work references and active disclosures addressed to the actor. Incoming titles come from the disclosed immutable snapshot, never the current private work; no body, owner identity or other recipient is emitted. Revocation removes an incoming reference on its next read; opening separately reauthorizes. Memory reads through the same transaction and validated durable log. Access verifies a credential on every request. The HTTP-facing route contract maps GET /v1/arrival, GET /v1/works/{work}, GET /v1/works/{work}/disclosures/{share}, POST /v1/commands and POST /v1/replies into existing authorized operations; exact raw command bodies remain validated by the original language. No wildcard routes, actor query parameters, query credentials or generic aggregate serialized. Response headers are prescribed; server adapters must apply them. This is a routing API contract, NOT an HTTP server, login or connected browser.

Acceptance: PostgreSQL integration with separate connections for sender and recipient, recipient discoverability, private scope, outsider exclusion, invalid credential and revocation. Existing fixture remains synthetic, no production data. CI and independent security review required. Next: real HTTP listener on a bounded runtime, OIDC/session verifier and registry enrollment, transport integration with two independently authenticated browser contexts, delivery, actual coauthorship, intelligence and grounded evidence. No external deploy, merge, billing or production DB. Existing bounded replay remains, pagination and load limits need review before scaling. No claim that art or all engineering is finished.
