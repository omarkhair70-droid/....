# 23 — الصوت يصبح مادة قابلة للتأليف / Presence 01.8
15 نوفمبر 2026. مرجع الحوار الأصلي ص97، ووثيقة 20، ونجاح World web/kernel في 947b24f.
## التجربة الحقيقية لا القرار النهائي
أضفنا موصلًا تجريبيًا لـ Web Speech API المحلي فقط (SpeechRecognition.processLocally). الاختيار ظاهر في المتصفحات التي تعلن دعم الواجهة المطلوبة؛ يتطلب اختيار الإنسان للتفريغ واللغة قبل التسجيل. اللغة ar-EG أو en-US قرار تجربة لا دعم مضمون. نتحقق من حزمة مثبتة بالفعل عبر available مع quality=dictation، ولا نستدعي install أو أي نموذج بعيد. إن تعذر المسار يبقى التسجيل مستقلًا. نمرر track فعليًا من نفس تسجيل MediaRecorder ولا نطلب إذن ميكروفون ثان من التطبيق.
## التأليف
يعرض النص الأولي أثناء الالتقاط بوصفه غير مراجع؛ النهائي فقط يدخل مسودة مرتبطة بـBlob الحالي في الذاكرة. لا استبدال لنص الإنسان، لا نقل أو حفظ تلقائي، لا اعتبار لكلمات غير نهائية. يراجع الإنسان المسودة ويضيفها صراحة. عند رفض أو فشل التسجيل لا نخلط نتائج جلسة جديدة مع الصوت السابق. المهل والإلغاء يتجاهلان أحداث الجلسة القديمة. هذه محاذاة على مستوى التسجيل، وليست timestamps لكل كلمة ولا حفظ نسب دائم.

## تحقق وليس ادعاء دقة
اختبارات بموصل اصطناعي: opt-in، حزمة مثبتة، عدم fallback، النص النهائي مقابل المؤقت، تعديل الإنسان، إلغاء وآثار متأخرة. لا تعتبر اختبارًا صوتيًا. لم نختبر دعم العربية المصرية أو سرعة/دقة الجهاز، أو إن كان محرك المتصفح يلتزم فعليًا بالمعالجة المحلية؛ نحتاج أجهزة حقيقية وقياسات شبكة، ومقارنة WASM/ONNX. لا ادعاء جودة إنتاجية. صححنا أيضًا أمر تجميع Vercel ليضم ملفات ES modules المستوردة؛ لم ننشر يدويًا أو ندمج main.
